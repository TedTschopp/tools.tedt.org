How the model works

Use one work class whose reviewers can substitute for one another. All calculations use averaged daily work.

  • Minutes per reviewed case = first-review minutes + extra-pass fraction × extra-pass minutes.
  • Review demand = requests × review fraction × minutes per reviewed case.
  • Team capacity = qualified reviewers × protected hours × 60 minutes.
  • Tomorrow's queue = maximum of zero and today's queue + new demand − capacity.
  • Maximum intake = chosen target × capacity ÷ review workload per incoming request.
  • Reviewer counts round up. Backlog-clearing staffing includes starting queue workload divided by modeled workdays.

Case equivalents divide remaining work by average review time. They can be fractional; real approvals remain whole decisions.

At exact capacity, an empty queue stays empty in this model. Any starting backlog remains, with no room for interruptions.

This model omits within-day bursts, reviewer scheduling, fatigue, skill differences, and repeated returns. It estimates workload, not actual waiting times or decision quality. A target below 100% is an assumption to investigate, not evidence that a workflow is safe.
